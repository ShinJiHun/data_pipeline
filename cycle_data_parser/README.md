## Platform Vision

This project started as a cycling activity data pipeline, but is evolving into a
**personal multi-sport & health data platform**.

The long-term goal is to integrate and analyze:

- Cycling activities (Garmin, Strava)
- Other outdoor activities (running, hiking, etc.)
- Health records (InBody OCR, body composition, workouts)
- Environmental context (weather, terrain)
- AI-assisted analysis and insights

Each data source is ingested independently, but unified at the database and
analysis layers to enable cross-domain insights.
